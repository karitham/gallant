Providers

  Choose a provider with --provider and a model with --model. Set
  GALLANT_PROVIDER and GALLANT_MODEL to change the defaults; the flags override
  them. The built-in default provider is opencode, and its default model is used
  when neither --model nor GALLANT_MODEL names one.

  opencode

    OpenCode Zen's System One gateway, serving TypeSafe's Jev.

    Models   jev-1.13, jev-1.13-free (default)
    API key  OPENCODE_API_KEY (required for jev-1.13; jev-1.13-free needs none)

      export OPENCODE_API_KEY=...
      gallant --provider opencode --model jev-1.13-free .

  cloudflare

    Cloudflare Workers AI, serving Cloudflare's Clef decision models. Clef reads
    up to 64K tokens and up to 64 rules per file.

    Models   clef (default), clef-flash
    API key  CLOUDFLARE_API_TOKEN (required; a Workers AI token)
    Account  CLOUDFLARE_ACCOUNT_ID (required)

      export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=...
      gallant --provider cloudflare --model clef-flash .

  liquid

    Liquid AI's d1 decision models. The hosted API serves d1.1 and d1-ultra.
    The open LFM3 decision models, d1-2B and d1-Omni-2B, run on llama.cpp
    (b11960 or later) and answer the same protocol at /v1/systemone.

    Models   d1.1 (default), d1-ultra; d1-2B and d1-Omni-2B on a local server
    API key  LIQUID_API_KEY (required for the hosted API)
    Base URL LIQUID_BASE_URL (default https://api.liquid.ai/decisions)

      export LIQUID_API_KEY=liquid_...
      gallant --provider liquid .

    To evaluate locally without a key, point LIQUID_BASE_URL at the server root:

      llama-server -hf LiquidAI/d1-2B-GGUF:Q8_0 -b 8192 -ub 8192
      LIQUID_BASE_URL=http://127.0.0.1:8080 gallant --provider liquid --model d1-2B .

  ollama

    A local Ollama server (0.35.0+). No API key. Models are discovered from the
    server, for example nimble (default), tev1, clef, clef-flash, and laya.

    Base URL  OLLAMA_HOST (default http://127.0.0.1:11434)

      gallant --provider ollama --model nimble .

  strands-decider

    A local Strands Decider server (0.1.0+). No API key. The served checkpoint
    is discovered from the server, and defaults to
    strands-decider-2B-qwen3.5-v1-2610.

    The server truncates state larger than the checkpoint's context window (4,096
    tokens for the shipped checkpoints). Start it with --strict-window to reject
    an oversized file instead, which gallant reports as a file error.

    The server answers one request at a time, so gallant serialises evaluations
    for this provider and --jobs has no effect on throughput. Files are still
    reported in order.

    Base URL  STRANDS_DECIDER_HOST (default http://127.0.0.1:8000)

      pip install strands-decider
      strands-decider serve StrandsAgents/strands-decider-2B-qwen3.5-v1-2610 --port 8000
      gallant --provider strands-decider .
