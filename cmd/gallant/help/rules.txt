Rule format

  A rule is a markdown file. Put rules in .agents/gallant, or in the directory
  named by --rules or GALLANT_RULES. gallant reads rules in subdirectories and
  ignores hidden files.

  A rule has optional frontmatter between two "---" lines, then the rule text:

    ---
    appliesTo: "*.go"
    type: noul
    ---
    # No debugging leftovers

    Report a violation when the file keeps code that only helped while it was
    written.

Frontmatter fields:

  appliesTo      A glob, or a list of globs, matched against the file name (not
                 the path). gallant uses the rule only when a glob matches.

  type           The question the model answers. One of:

                   noul    asks whether the file breaks the rule, and reports a
                           violation above minConfidence. Its text is the prompt
                           the model reads, so write the yes/no question
                           yourself, such as "Does this file violate the
                           following rule?" followed by the rule. A yes is a
                           violation.
                   choice  asks which option describes the file.
                   score   asks which level describes the file.

  criteria       For choice, a mapping of option to description. For score, an
                 ordered list of levels, from low to high.

  violation      For choice and score only. When the rule reports a failure:

                   violation:
                     if:            # any one of these fires a violation
                       useless: 0.5
                     unless:        # any one of these cancels it
                       useful: 0.7

                 Each entry names an option or level and the probability it must
                 be above to fire. The rule fails when some if entry fires and
                 no unless entry does. gallant prints a verdict line for the
                 rule, such as "fail (useless 0.95 > 0.5)", before the
                 outcomes. A passing rule is hidden unless --include-passing is
                 given. A noul states its threshold with minConfidence instead,
                 so it cannot declare a violation.

  minConfidence  For noul only. The probability of a violation above which the
                 rule fails, from 0 to 1 (default 0.5).

  The rule text after the frontmatter is sent to the model as written; nothing
  is prepended or appended to it.

Examples:

  noul:

    ---
    appliesTo: "*.go"
    type: noul
    minConfidence: 0.8
    ---
    Does this file violate the following rule?

    # Exported declarations need doc comments

    An exported declaration needs a doc comment.

  choice:

    ---
    appliesTo: "*.go"
    type: choice
    criteria:
      useful: "The comments explain intent or rationale."
      mixed: "Some comments add value, others repeat the code."
      useless: "The comments mostly restate the code."
    violation:
      if:
        useless: 0.5
    ---
    Classify the comments in this file.

  score:

    ---
    appliesTo: "*.md"
    type: score
    criteria:
      - "Easy to read"
      - "Somewhat hard"
      - "Very hard"
    violation:
      if:
        "Very hard": 0.5
    ---
    Rate how hard this document is to read.
